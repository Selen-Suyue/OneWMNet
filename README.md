# OneWM project page

Project website for **Can World and Action Modeling Benefit Each Other under Unified Causal Training?**

## Local preview

Run `python3 scripts/serve.py --port 4174`, then open http://127.0.0.1:4174.
The static page requires no build step. Relative asset URLs support GitHub Pages project paths.

## Media and display data

- Three full real-robot videos, twelve action-conditioned prediction examples, and six complete imagined rollouts. All videos are silent.
- Optional background music: **みちしるべ — 茅原実里**. Use the hero's music button to play or pause; music is off by default and independent of the experiment videos.
- Prediction examples show recorded reference end-effector motion alongside the actual conditioning controls.
- Imagined rollouts show the saved predicted controls. The relative action path is not a measured end-effector trajectory. Each case includes all 16 rounds; the presentation pauses illustrate causal order, not inference latency.
- Display manifests contain only public descriptions, media filenames, playback timing, and the numeric controls needed by the visualizations.
- The hero artwork is an AI-generated editorial illustration, separate from experimental evidence. Institution logos retain their original appearance.
- GitHub links to the [OneWM research repository](https://github.com/Interactive-Active-AI/OneWM), and Paper opens its [PDF preview](https://github.com/Interactive-Active-AI/OneWM/blob/main/assets/OneWM-preview.pdf). The arXiv link remains a placeholder.

The scientific limitations of the examples are described in the page's expandable notes.
